Projeto Final - Curso de Java Spring Boot + AWS

O objetivo deste projeto é permitir que cada aluno desenvolva individualmente um backend completo utilizando Java Spring Boot, banco de dados PostgreSQL e deploy em uma instância AWS EC2.

Objetivo do Projeto

Desenvolver uma API REST completa para gerenciamento de clientes. O frontend fornecido pelo professor será utilizado para validar se os endpoints foram implementados corretamente.

Tecnologias Obrigatórias

  • Java 17
  • Spring Boot
  • Spring Web
  • Spring Data JPA
  • PostgreSQL
  • AWS EC2
  • GitLab
  • Swagger/OpenAPI

Entidade Obrigatória

Cliente
--------------------------------------------------
id -> Long
nome -> String
cpf -> String
email -> String
telefone -> String
sexo -> String
dataNascimento -> String

Endpoints Obrigatórios

POST    /clientes
GET     /clientes
GET     /clientes/{id}
GET     /clientes/cpf/{cpf}
GET     /clientes/nome/{nome}
GET     /clientes/sexo/{sexo}
PUT     /clientes/{id}
DELETE  /clientes/{id}

Regras do Projeto

  • Cada aluno deverá possuir sua própria instância EC2.
  • O backend deverá estar publicado e acessível pela internet.
  • O frontend fornecido deverá funcionar sem alterações.
  • Todos os endpoints devem retornar JSON.
  • Os nomes dos atributos devem seguir exatamente o padrão especificado.
  • O projeto deve possuir integração com PostgreSQL.
  • O projeto deve possuir Swagger funcionando.
  • O código deverá estar versionado no GitLab.

Configuração obrigatória para funcionamento do Front

Como este frontend HTML poderá ser aberto diretamente no navegador, o backend precisa liberar chamadas externas no controller. Para isso, inclua a anotação abaixo na controller de clientes.

@CrossOrigin(origins = "*")

Exemplo completo:

@CrossOrigin(origins = "*")
@RestController
@RequestMapping("/clientes")
@RequiredArgsConstructor

public class ClienteController {
    // endpoints do projeto
}

Critérios de Avaliação

  • Funcionamento completo da API.
  • Deploy funcionando na AWS.
  • Integração correta com o frontend.
  • Organização do código.
  • Padronização da arquitetura Controller, Service, Repository e Model.
  • Persistência correta dos dados.
  • Versionamento no GitLab.
